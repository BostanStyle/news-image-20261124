Six stories: the Riyadh tower strike, Huawei found guilty in the US, the Hamas security chief killed in Gaza, Ukraine's strikes on Russian ships, four tankers hit mines in the Strait of Hormuz, and a Turkish helicopter crash.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies the bundled `entry.png` (1024×1024 PNG, ~109 KB) to `out/entry.png`, deterministically, with no network.
